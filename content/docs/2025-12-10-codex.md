## Codex

1. Registration

2. Create config folder and files

3. Install nvm: `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash`

4. Install latest npm: `nvm install --lts`

5. Install codex/claude/gemini via npm:

    ```sh
    npm i -g @anthropic-ai/claude-code@latest
    npm i -g @openai/codex@latest
    npm i -g @google/gemini-cli@latest
    ```

6. Use cli: `claude/codex/gemini`

## Claude

```sh
jq '. + {"hasCompletedOnboarding": true}' ~/.claude.json > /tmp/tmp.json && mv /tmp/tmp.json ~/.claude.json
```
